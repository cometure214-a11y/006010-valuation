## 1. 整体思路

```
最新季报前十大持仓(权重 w_i)  ─┐
                                ├─▶  加权求和  ─▶  估算盘中变动%  ─▶  估算净值
个股实时行情(盘中收益 r_i)     ─┘        │
                                        └─▶  与披露快照/回归校准交叉验证(判断是否可信)
```

核心假设：**最新披露季报（2026-06-30 Q2）的前十大持仓权重，仍能近似代表基金当前真实暴露。**
该假设在"未大幅调仓"时成立；一旦调仓，需用第 4 节的回归校准 / 漂移告警来约束可信度。

---

## 2. 核心算法（公式）

记前十大第 `i` 只股票：占净值权重 `w_i`（单位 %）、盘中收益率 `r_i = (现价 − 昨收) / 昨收`。

### 2.1 朴素披露权重法（标准盘中估值）
```
est_chg = Σ (w_i / 100 × r_i)          # 残差(前十大外 ~17%) 假设收益为 0
```

### 2.2 归一化法（假设残差收益 = 重仓收益）
```
est_chg = Σ (w_i × r_i) / Σ w_i        # 把仅覆盖的部分按重仓表现放大到全组合
```

### 2.3 估算净值
```
est_NAV = 上一交易日单位净值 × (1 + est_chg)
```

> 两种法都给，差异即"残差假设"带来的区间宽度。今日：朴素 +4.58% / 归一化 +5.50%。

## 4. 校准与增强（针对"部分调仓 / PCB"）

### 4.1 回归校准暴露（抑制权重失真）
- 手册 3.3/3.4 用 110 天日收益回归得到**真实总股票暴露 ≈ 81.5%**（披露 83.16%，漂移 −1.64pct，R²=0.97）。
- 用法：把基准暴露从 83.16% 调到 81.5%，或用回归系数替代裸披露权重；手册 CV 已证校准法样本外 RMSE 更低（0.75 < 0.86）。

### 4.2 PCB 篮子单跑（专治"经理 8/11 看多 PCB"）
- 若经理已部分调入 PCB 且不在披露十大，需单独算一项加回：
  - 深南电路 002916 / 沪电股份 002463 / 胜宏科技 300476，**等权**日收益。
  - **今日实测（2026-08-20 盘中）**：深南电路 +1.74% / 沪电 +1.97% / 胜宏 +4.64% → **等权 +2.78%**。
- 解读：PCB 篮子(+2.78%) 远低于光通信十大(等权 +5.46%)。若已"减光通信、加 PCB"，则当前光通信重仓估算**偏高**；若"保留光通信、加 PCB"，真实变动介于两者之间。

### 4.3 漂移阈值告警
- 漂移 = 回归总暴露 − 披露合计。若 **> ±8pct** → 判定披露快照失效、估算不可信，等 Q3 季报（约 10 月底）重跑。

## 5. 误差来源与容差

| 来源 | 说明 | 量级 |
|---|---|---|
| 残差假设为 0 | 前十大外 ~17% 仓位收益当 0 | 所有公开估值系统性存在 |
| 权重失真 | 部分调仓 → 真实权重 ≠ 披露权重 | 调仓越狠越大 |
| PCB 漏算/错向 | 经理看多 PCB，已加/已置换 → 漏算或错算方向 | 可能 ±0.5~2% |
| 非交易时段 | 午休/收盘行情冻结，估算=最新快照 | 交易时段才实时 |

**建议容差**：盘中估值 ±1~3%，调仓活跃期取上限。
