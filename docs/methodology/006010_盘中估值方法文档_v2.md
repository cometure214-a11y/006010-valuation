## 1. 方法论转变（为什么不再反推个股）

仅凭每日基金净值，**无法准确识别具体持有哪些股票**——因为光通信、PCB、半导体个股走势高度相关（本数据 r≈0.6~0.73），回归会把"行业整体上涨"误判为"仍持有原十只股票"。

更稳定的做法是**估计行业/风格暴露**：

```
光通信暴露  +  PCB暴露  +  半导体暴露  +  市场暴露  +  现金/债券/残差  ≈ 100%
```

再用各行业的**篮子收益**（多只股票等权/市值加权）做盘中估值。这比"反推精确个股"鲁棒，也更符合基金"渐进调仓"的现实。

## 2. 三层方法

### L1 · Q2 披露权重基准（保留为锚）
```
基准收益 = Σ (Q2披露个股权重 × 当日个股涨跌幅)
```
输出三个口径形成**区间**而非定点：
- **朴素估值**：前十大之外收益按 0 计算 → 今日 **+4.39%**
- **归一化估值**：将前十大表现放大到全组合（÷前十大合计权重 83.16%）→ 今日 **+5.28%**
- **行业替代估值**：对疑似调仓部分，用 PCB 篮子替代部分光通信权重（假设调仓 10%~20%）→ 今日 **+4.10%~+3.81%**

### L2 · 行业暴露反推（风格而非个股）
```
当前组合 ≈ 光通信 ω1 + PCB ω2 + 半导体 ω3 + 市场 ω4 + 残差(现金/其他)
盘中估算收益 = ω1×光通信篮子收益 + ω2×PCB篮子收益 + ω3×半导体篮子收益 + ω4×市场篮子收益
```
行业篮子采用多只股票**等权**（生产环境建议改为市值加权或波动率调整权重，不宜长期简单等权）。

### L2.5 · 行业因子模型（2026-08-20 集成，替代原 L2 静态口径的核心）

用**行业篮子日收益**（而非个股）对基金日收益做**滚动约束回归**，反推动态暴露：
```
基金日收益 = β1×光通信篮子 + β2×PCB篮子 + β3×半导体篮子 + β4×市场篮子 + ε
```
- 因子收益率与基金涨跌幅**统一为百分比量纲**（否则 Σβ≤1 约束会把系数压碎，这是初版踩过的坑）；
- 参数：窗口 `W=40`、步长 5、半衰期 20（匹配周频换手）、平滑 λ1=0.01 + Q2 先验 λ2=0.03；
- **盘中预测 = 今日因子实时收益 × 截至昨日收盘回归出的 β**（无未来泄漏）；回测即"预测次日"。

**Q3 回测对比（决定性证据）**
| 指标 | 静态个股归一化 | 行业因子滚动约束回归 | 提升 |
|---|---|---|---|
| MAE | 0.75% | **0.42%** | **↓44%** |
| RMSE | 1.03% | **0.61%** | **↓41%** |
| 相关性 | 0.994 | **0.996** | 略升 |
| 8月中旬起偏差 | 系统性 +0.8~2.7% | 收敛（模型捕捉到调仓） | — |

暴露轨迹（模型自动识别）：7 月光通信≈90% → 8/3 起分散 → 8/6~11 PCB 升至 4.3% → 8/13 至今 **光通信 80% / PCB 7.3% / 大盘 11.7%**（本版最新 β：75.8% / 12.7% / 9.6%）。

### L3 · 滚动约束回归（反推 ω 的核心）
用每日官方净值涨跌幅，对行业篮子收益做滚动回归：
```
基金日收益 = β1×光通信篮子 + β2×PCB篮子 + β3×半导体篮子 + β4×市场篮子 + ε
```
约束：
```
βi ≥ 0                       # 不允许负暴露
Σβi ≤ 100%                   # 其余为现金/债券/残差
当前权重不相对前一天剧烈跳变   # 平滑
当前权重尽量靠近 Q2 披露权重   # 先验
```
优化目标（逐日滚动求解）：
```
最小化：
    历史拟合误差
  + λ1 × N × ‖当前权重 − 前一天权重‖²      (平滑，渐进调仓)
  + λ2 × N × ‖当前权重 − Q2权重‖²          (贴近披露)
```
> N 为窗口内样本数，使惩罚项与拟合项量纲一致。本版默认 `W=60, λ1=0.015, λ2=0.03`，Q2 先验 `[光通信=0.83, PCB=0, 半导体=0, 市场=0]`。

## 5. 对你 5 点修正的逐条落实

1. **"真实总股票暴露 81.5%"措辞修正** — 准确说应是**"对所选股票篮子的有效暴露"**，不等同基金真实股票仓位（残差里可能含其他股票/现金）。本版 L3 直接输出 `Σβ + 残差`，残差≈1.9%（因子模型版，接近满仓股票）。
2. **只用前十大回归易误判** — 本版用**行业篮子**（光通信/PCB/半导体/市场）而非个股做因子，降低"行业涨=仍持原股"的误判；但 §4 因子相关性提示仍有限度（r=0.72）。
3. **PCB 三股只是候选，不能单凭观点/单日定调仓** — 须同时确认：①连续多日官方净值误差；②PCB 系数加入回归后稳定为正；③模型权重连续数日向 PCB 漂移；④官方盘中估值系统性低于 Q2 模型。**当前 ②③ 已开始满足**（PCB 系数全窗口为正且短窗抬头），但 ①④ 仍需你按 §7.4 用官方数据验证。
4. **禁止未来数据泄漏** — 当天盘中只用"前一日及以前"数据；当日官方净值绝不参与当天权重反推（回归窗口严格止于 T−1，预测用当日因子实时收益×T−1 回归的 β）。
5. **纳入估值误差形成置信区间** — 已用近 40 日样本外误差（均值/波动）动态给出中心 ±1.5σ 区间。

## 6. 误差来源与容差

| 来源 | 说明 | 量级 |
|---|---|---|
| 残差假设为 0 | 前十大外 ~17% 仓位收益当 0 | 所有公开估值系统性存在 |
| 行业篮子共线 | 光通信~PCB r=0.72，小幅跨行业调仓难分离 | 可能误并≤10%至光通信 |
| 权重失真 | 实际调仓 ≠ 披露权重 | 调仓越狠越大 |
| 非交易时段 | 午休/收盘行情冻结 | 交易时段才实时 |

**建议容差**：盘中 ±1~3%，调仓活跃期取上限；本版统计带 ±1.5σ≈±1.0%。

## 12. 并行方案：精确个股反推（方案B · 持仓重建 / 组合复制）

你提出"反推精确个股"也是一条值得做的思路，故在方案A（行业暴露）之外**并行**做一套"从基金日收益反推具体持仓"的方案，作为交叉验证。这是金融工程里成熟的 **组合复制(portfolio replication)** 问题。

### 12.1 算法
给定基金日收益向量 `y` 与候选股日收益矩阵 `X`（每列一只股票），求解：
```
min ‖y − Xβ‖²  +  λ·‖β‖₁        (Lasso 稀疏选择个股)
s.t.  β ≥ 0, Σβ ≤ 100%           (非负 + 满仓约束)
```
实现两路互为印证：
- **方法A 非负 LASSO**：`LassoCV(cv=5, positive=True)` 交叉验证选 λ，再 `positive=True` 求稀疏解 → 选出"被持有的若干只"。
- **方法B NNLS + Bootstrap(200次重采样)**：`scipy.nnls` 求最优权重，Bootstrap 给每只股权重的 90% 置信区间与"入选频率"（权重>1% 的比例）。
- 窗口 `W=60` 日（≈Q2 后当前 regime），**严格止于 T−1，无未来泄漏**。

### 12.4 关键诚实结论（实测）
1. **两方案一致**：均确认"光通信主导 ~75~90%"，今日涨跌幅落在同一区间（2.7%~4.4%）→ 方向可信。
2. **干扰股总权重 = 0.00%** → 模型**没有错选**白酒/银行/锂电/医药/家电/保险/电力等无关风格，方法有效性得到验证。
3. **精确个股权重不可靠（核心局限）**：推断权重与 Q2 披露权重的相关系数仅 **r=0.18**（远低）。原因正是 §1 的"共线"——光通信 10 股走势高度同步，回归无法唯一确定每只的精确权重（解不唯一）。**这从实证上印证了"行业暴露比精确个股更稳"的判断。**
4. **PCB 线索**：方案B 给 PCB ≈7.9%（胜宏 5.1%+沪电 2.8%+深南入选），方案A 因子模型给 12.7%（含大盘分散）——**两方案均支持"已部分调 PCB"**，且方案A 短窗系数持续抬升。受光通信~PCB 共线（r=0.72）干扰，精确比例仍须用 §7.4 四条硬标准持续观察。

> 结论：**方案B 的价值不在"给出精确个股清单"（做不到），而在"交叉验证方案A 的光通信主导结论 + 探测 PCB 调仓线索 + 证明干扰股被正确排除"**。二者分工：盘中量级监控看方案A；调仓线索挖掘看方案B 的 PCB 权重与入选频率。
