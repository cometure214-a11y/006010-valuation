## 0. 总原则（最重要，先读）

> **本工具的目标不是精确还原第三季度真实个股持仓，而是尽可能降低盘中估算与收盘官方净值之间的误差。**

- Q2 披露持仓作为初始基准，行业因子模型、PCB 调仓比例模型和个股反推模型作为**不同预测器**；最终结果按近期样本外预测误差加权。
- 输出中的"光通信、PCB、市场"等数值属于**模型有效暴露，不等同于基金真实持仓比例**。
- PCB 目前出现持续为正的模型信号，说明"部分调入 PCB"的假设有支持；但因光通信与 PCB 相关性较高（r=0.72），**暂不能据此确认真实 PCB 持仓比例**，只输出"调仓概率/有效替代比例"。

## 2. 五模型组合架构

```
P1  Q2 静态基准      r_q2 = Σ(Q2披露权重 × 今日个股收益)
P2  调仓替代比例     r_q2 + θ_pcb×(r_pcb−r_q2) + θ_m×(r_m−r_q2)
P3  行业因子         β1×光通信 + β2×PCB + β3×半导体 + β4×市场
P4  层级组合         行业总比例(β) × 行业内Q2披露相对权重
P5  个股辅助反推     LASSO/NNLS 今日收益均值（仅作辅助特征）

P_final = Σ w_i × P_i     w_i ∝ 1/(MAE_i + 0.05%)，单模型权重 ≤70%
r_final = P_final + median(e_recent)     # 历史偏差修正
```

### 2.1 P1 · Q2 静态基准（锚）
```
r_q2,t = Σ (Q2披露个股权重 × 个股当日收益)
```
保留为"什么都不假设"的基准。今日 **+4.39%**。

### 2.2 P2 · 调仓替代比例模型（意见§二核心新增）
直接估计"从 Q2 组合切换了多少"，而非解释多个高度相关的 β：

```
y_t = r_q2,t + θ_pcb,t × (r_pcb,t − r_q2,t) + θ_m,t × (r_m,t − r_q2,t) + ε_t

θ_pcb = 从 Q2 组合切换到 PCB 组合的有效比例
θ_m   = 从 Q2 组合切换到市场/其他风格的有效比例
```
约束：`0 ≤ θ_pcb ≤ 35%`，`0 ≤ θ_m ≤ 25%`（上限通过历史滚动回测选择，**不代表真实持仓上限**）。

参数估计目标（滚动，半衰期加权）：
```
min  Σ q_k × [y_k − ŷ_k]²
     + λ1×(θ_pcb,t − θ_pcb,t−1)² + λ2×(θ_m,t − θ_m,t−1)² + λ3×θ_pcb,t²
```
- `q_k` 时间权重（越近越高）；`λ1/λ2` 防跳变；`λ3` 防无证据时过度加 PCB；
- **每天只用截至前一交易日的数据估计**；盘中预测用 `θ_{t−1}`。

今日：**θ_pcb=7.1%、θ_m=0%**，P2 预测 **+4.18%**。

### 2.3 P3 · 行业因子模型
```
基金日收益 = β1×光通信 + β2×PCB + β3×半导体 + β4×市场 + ε
```
约束：`βi ≥ 0`、`Σβ ≤ 1`、平滑 + Q2 先验。今日 β：光通信 78.5% / PCB 9.6% / 半导体 0% / 市场 7.4% / 残差 4.5%。P3 预测 **+4.36%**。

### 2.4 P4 · 层级组合反推（意见§三新增）
行业总比例动态、行业内部权重固定：
```
当前个股权重_i = 当前行业权重_g × Q2时期个股i在行业g内的相对权重
```
- 光通信内部：沿用 Q2 披露相对权重（10 只归一化）；
- PCB 内部：等权（或历史波动率加权，可作为后续增强）；
- **不使用 LASSO 结果直接替换个股权重**。
目的不是还原持仓，而是提高"当日个股差异大"时的预测准确度。P4 今日 **+4.36%**。

### 2.5 P5 · 个股辅助反推（意见§九，定位降级）
读取 `fund_holdings_infer.py` 输出（LASSO/NNLS 今日收益均值），仅作辅助。今日 **+3.68%**。

## 4. 置信度与误差管理（意见§五、§六）

### 4.1 置信度三维定义（替换原 R²>0.9 规则）
> R² 只表示对历史波动的解释程度，不能单独代表盘中预测准确率，也不能证明 β=真实持仓。

| 级别 | 条件 |
|---|---|
| **高** | 近20/40日 MAE 均低，模型间分歧小（<1.5pct），调仓比例 θ 稳定 |
| **中** | 误差可接受，但模型间分歧明显，或 θ 波动较大 |
| **低** | 近期误差持续扩大，模型方向不一致，或因子相关性过高 |

今日：**高**（P3 MAE 0.43%，分歧 0.71 pct，θ_pcb 稳定 0.071）。

### 4.2 历史误差偏差修正（意见§六）
```
e_t = 实际官方净值收益 − 当日模型预测收益
r_final,t = r_model,t + median(e_recent)   # e_recent=近20/40日样本外误差
```
- 优先用**中位数或指数加权均值**，避免单日极端行情影响；
- 今日近40日误差中位数 **−0.20%**（模型平均高估 0.20%）→ 中心 −0.20% 修正。

### 4.3 收盘误差跟踪（持续运行）
每交易日记录 `实际 − 模型`，滚动更新 MAE/中位数/σ，形成经验预测区间（中心 ±1.5σ）。

## 6. PCB 调仓三级信号（意见§七）

> 本工具不直接确认真实 PCB 持仓，只输出 **PCB 调仓概率和有效替代比例**。

| 级别 | 条件 |
|---|---|
| **弱信号** | θ_pcb 为正，但仅单一窗口/单一篮子出现 |
| **中等信号** | θ_pcb 在 10/20/60 日窗口均为正，且加入 PCB 后样本外 MAE 下降 |
| **强信号** | θ_pcb 连续多日上升 + 不同 PCB 篮子一致 + Bootstrap CI 大部分>0 + 滚动样本外误差稳定下降 |

只有**强信号**才允许界面显示"PCB 调仓概率较高"；**不能显示"已调入 PCB"**。
今日：**中等信号**。

## 7. 模型选择与组合（意见§十）

每日生成 P1~P5，按最近20日样本外 MAE 加权：
```
model_weight_i ∝ 1 / (MAE_i + 0.05%)
```
- 单模型权重 **≤70%**（防主导）；
- 最终评价指标只用：**近10日MAE、近20日MAE、近40日MAE、近20日方向准确率**；
- R² 仅作辅助，不作为模型选择标准。

---

## 8. 核心纪律（不变）

1. **无未来数据泄漏**：当天盘中只用 T−1 及以前数据；当日官方净值绝不参与当天参数估计；
2. **参数选择禁止用当天结果**：只能用预测日之前的数据；
3. **β/θ 解释为有效暴露**，不解释为真实持仓；
4. **个股反推不用于认定持仓**：LASSO/NNLS 在相关股间解不唯一，个股结果须经多窗口/多候选池/多篮子稳定性检验。
