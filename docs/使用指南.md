# 006010 盘中估值系统 - 使用指南

面向三种使用场景：**盘中看估值 / 每日收盘更新 / 部署到手机**。

---

## 场景一：盘中看估值（最快）

### 方式 A：手机/电脑浏览器（已部署云端）

打开即可，无需安装任何东西：

```
https://cometure214-a11y.github.io/006010-valuation/
```

- 页面打开时**自动拉取**前十大股票实时行情 → 显示"实时行情快照"（简单加权 + 归一化 + 前十大逐股）
- **主数字**（五模型完整估算）是最近一次手动更新的快照
- 盘中显示"今日盘中估算"，收盘后（净值已公布）自动切换"下一交易日估算"

### 方式 B：本地 Web（不想用云端时）

1. 双击 `scripts\手机端估值面板.bat`
2. 手机连同一 WiFi，浏览器打开屏幕显示的 `http://IP:8080`

### 方式 C：桌面 GUI

1. 双击 `scripts\打开估值面板.bat`
2. 窗口显示完整模型估值，点"刷新"按钮重跑模型

## 场景二：每日收盘后更新完整估值

> 目标：让主数字（五模型）反映最新净值与最新持仓估计。

| 方式 | 操作 | 说明 |
|---|---|---|
| **本地一键** | 双击 `deploy\一键更新并推送.bat` | 自动：抓数据→方案B→方案A→生成页面→推送到 GitHub |
| **云端手动** | GitHub 仓库 → Actions →「006010 盘中估值部署」→ **Run workflow** | 云端完整跑一遍，约 3 分钟 |

**什么时候需要更新**：
- 每个交易日**收盘后**（净值公布后）跑一次，让模型学习当天实际表现
- 需要看**下一交易日**开盘前参考时

## 常见问题

**Q: 主数字和实时快照数字不一样？**
A: 正常。实时快照=纯 Q2 前十大口径（假设无调仓）；主数字=五模型集成（考虑调仓替代、行业因子等），更接近真实。

**Q: "归一化 +5.28%" 是什么？**
A: 把前十大股票权重缩放至 100% 后的理论涨跌（假设"前十大=整个基金"）。它回答"如果基金只持有这10只，今天涨多少"，是参照不是结论。

**Q: 为什么估值和官方净值有误差？**
A: ①季报后可能调仓 ②光通信与PCB高度相关(r≈0.71)导致识别误差 ③盘中行情与基金估值时点有时间差。回测 MAE≈0.8%，误差 ±1.5% 以内属正常。

**Q: 腾讯接口没返回当天数据怎么办？**
A: 已内置"实时行情补齐"逻辑：日K缺当天时用实时行情收盘价补上。若仍未更新，等 20:00 后重试。

**Q: git push 提示要登录？**
A: 项目已配置本地凭据存储（token 存 `~/.git-credentials`），一般无需再输入。90 天 token 过期后重新生成。
